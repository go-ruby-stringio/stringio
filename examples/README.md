# Examples

Runnable, pure-Ruby usage of the `stringio` library, verified under the
[rbgo](https://github.com/go-embedded-ruby/ruby) interpreter.

```sh
rbgo examples/stringio_usage.rb
```

| File | Shows |
| --- | --- |
| `stringio_usage.rb` | Writing with `puts`/`print`/`write`, line reads via `gets`/`readlines`, random access with `seek`/`read`/`pos`/`eof?`, and chained `<<` appends. |
